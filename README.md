# Diabetes im Klinikalltag – Fortbildungsmaterial

Fallakten für die Gruppenarbeit einer Pflegefortbildung. Alle Patientendaten sind frei erfunden.

Veröffentlicht über GitHub Pages: https://mohr-fbg.github.io/diabetes-fortbildung/

Der Ordner `qr/` enthält QR-Codes zu den Seiten für die PowerPoint-Präsentation.

- Block 1: `fall1.html` bis `fall3.html` (Fallakten)
- Block 2: `spiel.html` (Planspiel „Spätdienst auf Station 4“, Neustart mit `spiel.html?neu`)
